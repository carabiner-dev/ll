# Carabiner Lamplight Client

This repository contains the client library for Carabiner's
Lamplight service. Lamplight is Carabiner's permissions system.
It is not open source (for now at least!), but the client is.

You are welcome to use this client to interact with the lamplight
service in your own applications, but we recommend that if you
develop an app that needs IAM capabilities you use the higher
livel libraries of our SDK.
